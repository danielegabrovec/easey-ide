# Scrittura rapida

Per provare un'idea in pochi secondi, **senza progetto**: JavaScript, TypeScript, Python, SQL, HTML, C, C++, C#, Java e Rust.

- Scegli il linguaggio in alto, scrivi, e il risultato compare **accanto alle righe** (Ctrl+Invio o F5 per eseguire di nuovo).
- Se il programma chiede dati (`input()`, `scanf`, `Scanner`), scrivili nel riquadro **Input**.
- Un ciclo infinito non blocca niente: dopo il tempo massimo il programma si ferma da solo (o premi **Ferma**).
- **Livello di aiuto**: Spento, Leggero, Intermedio, Forte decide quanto suggerisce l'editor e l'AI.
- **Genera con AI**: descrivi a parole cosa vuoi e l'assistente scrive il codice da guardare.

C, C++, C#, Java e Rust usano i compilatori installati sul PC: se mancano, una scheda spiega come installarli.
I tuoi esperimenti si salvano nei Documenti, cartella *Easey IDE/Scrittura rapida*.
