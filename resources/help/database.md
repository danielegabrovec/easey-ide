# Database e SQL

Il pannello **Database** (Ctrl+Maiusc+D) mostra i database del progetto (SQLite o PostgreSQL incorporato) con tabelle e colonne.

- **Nuova query SQL**: un file `.sql`; **Ctrl+Invio** esegue l'istruzione sotto il cursore e i risultati arrivano in basso.
- **Query visuale**: costruisci la domanda trascinando le tabelle; l'SQL si scrive da solo.
- **Diagramma ER**: le tabelle e i loro collegamenti.
- **Istantanee**: una copia del database da ripristinare se una prova va storta.

Senza un database nel progetto si lavora sul database **in memoria**: è comodo per provare, ma si svuota chiudendo l'app (Easey IDE te lo ricorda). Per tenere i dati crea un database con **+**.

Per qualcosa di più grande (tabelle disegnate, dati come in Excel, maschere) c'è l'app sorella **Easey DB**.
