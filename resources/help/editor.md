# L'editor del codice

Qui scrivi i file del progetto: HTML, CSS, JavaScript, TypeScript, SQL e anche Python, C, C++, C#, Java e Rust.

## Mentre scrivi

- I **suggerimenti** compaiono da soli: frecce per scegliere, Invio o Tab per accettare.
- Con l'assistente AI acceso, un **suggerimento in grigio** propone il resto della riga: **Tab** lo accetta, **Ctrl+→** una parola alla volta.
- Le righe sottolineate in rosso sono **errori**: passa sopra con il mouse per leggerli, oppure apri **Problemi** (il numero rosso nella barra di stato).

## Comandi utili

| Cosa | Tasti |
|---|---|
| Salva / salva tutto | Ctrl+S / Ctrl+Alt+S |
| Trova un file del progetto | Ctrl+P |
| Tutti i comandi | Ctrl+Maiusc+P |
| Chiedi un suggerimento all'AI | tasto destro → Chiedi suggerimento |
| Torna a una versione di prima | tasto destro sul file → Cronologia locale |

Il salvataggio automatico è acceso di serie: lo cambi nelle Impostazioni.
