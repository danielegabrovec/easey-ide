# Terminale, problemi e passo-passo

- **Esegui nel terminale** (Ctrl+F5) fa girare il file JavaScript o TypeScript aperto: ciò che scrive il programma e ciò che digiti tu passano dal **Terminale**.
- Il **Terminale** è anche una PowerShell vera (pulsante «Nuovo terminale» nella barra in alto): ci puoi scrivere comandi come `node main.js` o `git status`.
- **Problemi** elenca gli errori e gli avvisi di tutti i file aperti; un clic porta alla riga.
- **Esegui passo passo** (Ctrl+F10) esegue il programma JavaScript o TypeScript una riga alla volta e mostra le variabili: è il modo migliore per capire dove sbaglia.

## Un errore che non capisci?

Copia il messaggio (anche dal registro **Attività** in basso) e chiedilo all'assistente con **/errore**: te lo spiega in italiano e propone la correzione.
