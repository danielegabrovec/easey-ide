# Il designer: la pagina senza scrivere codice

Il designer modifica il file HTML e il CSS al posto tuo, cambiando solo le righe che servono.

1. **Palette** a sinistra: trascina un titolo, un pulsante, un'immagine o una **sezione pronta** nella pagina (oppure un clic per metterla dopo l'elemento scelto).
2. Clic su un elemento per sceglierlo; **doppio clic** su un testo per scriverlo.
3. **Ispettore** a destra: colori, caratteri, spazi, bordi. La scheda **Sito** cambia il tema di tutte le pagine.
4. **Affianca codice** (Ctrl+Alt+K) mostra l'HTML accanto: clicchi un elemento e vedi le sue righe.

## Trucchi

- **Ctrl+rotellina** ingrandisce, **Ctrl+0** adatta alla finestra, spazio + trascina sposta la vista.
- **Ritocchi consigliati** trova contrasti illeggibili, immagini senza descrizione, pulsanti troppo piccoli: «Correggi» li sistema con un clic.
- **Ctrl+Z** annulla qualunque modifica.
